# Заметки перед началом работы

## Технический стек
- Python
	- uvicorn
- PostgreSQL
- JavaScript
	- Typescript
	- Vue/React

## Функциональные требования

1. Реализовать систему работы с указанной структурой данных:

2. Учесть добавление/редактирование/валидацию и удаление данных из каждой таблицы.  
- Возможности админа:
	- Работать с данными из всех таблиц
	- Видеть всех пользователей
	- Включать/отключать пользователей
- Возможности пользователя:
	- Работать с данными из всех таблиц, но из таблицы «Weighting» видит только свои записи

3. Реализовать регистрацию пользователя для работы с системой
- Регистрация через почту и пароль
- Ссылка активации отправляется на почту
- Логины пользователей уникальны. 
- После регистрации пользователь создаётся в не активном состоянии.
- Становится активным переходя по ссылке полученной с регистрации

4. Обеспечить API для работы с системой

5. Обеспечить front-end для работы с системой (технологический стек для front-end на выбор собеседуемого, но оптимально – Vue/React).
- Доступно 5 страниц
	- Главная (Добавление информации о взвешивании)
	- Тип животного
	- Порода
	- Животное
	- Взвешивание
	- Пользователи (для админа)
- На главное странице имеется поля для ввода, выпадающие списки всех обязательных данных для добавления записи взвешивания

## База данных

### Таблицы
- [ ] animaltype
- [ ] breed
- [ ] animal
- [ ] weighting
- [ ] users

#### AnimalType - поля таблицы
- [ ] идентификатор записи
- [ ] наименование типа животного

#### Breed - поля таблицы
- [ ] идентификатор записи
- [ ] наименование породы
- [ ] тип животного (relation to AnimalType)

#### Animal - поля таблицы
- [ ] инвентарный номер
- [ ] пол
- [ ] кличка
- [ ] дата прибытия
- [ ] возраст прибытия (в месяцах)
- [ ] порода (relation to Breed)
- [ ] данные об одном родителе

#### Weighting - поля таблицы
- [ ] идентификатор записи
- [ ] животное (relation to Animal)
- [ ] дата взвешивания
- [ ] вес в кг

#### Users - поля таблицы
- [ ] идентификатор записи
- [ ] логин пользователя
- [ ] почта пользователя
- [ ] хэш-значение пароля
- [ ] роль
